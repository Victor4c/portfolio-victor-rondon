# Portfólio Profissional — Victor Gabriel de Sales Rondon

Website responsivo em Dark Mode Editorial & Tech apresentando projetos end-to-end de AI Builder, consultoria econômico-financeira e central categorizada de certificações e produção acadêmica da UFMT / NuPES.

## 🚀 Tecnologias
- **Frontend:** HTML5 Semântico, CSS3 Moderno (Design Tokens, Glassmorphism, Microinterações), JavaScript Vanilla (ES6+).
- **Dados:** Estruturação estática e desacoplada em `data.js`.
- **Segurança & LGPD:** Certificados públicos sanitizados automaticamente via script Python com tarja em CPF e RGA/matrícula.

## 📁 Estrutura
- `index.html`: Página principal com seções de Hero, Métricas, Projetos, Certificados e Experiência.
- `styles.css`: Design System completo inspirado em interfaces modernas (Linear/Vercel).
- `data.js`: Base de dados dos 4 projetos principais e dos 25 certificados únicos.
- `script.js`: Sistema de busca instantânea, filtragem por categorias e modais interativos de arquitetura e visualização de documentos.
- `assets/certificados/`: 25 certificados e comprovações oficiais sanitizados.
